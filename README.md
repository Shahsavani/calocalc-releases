# کالری‌یاب (CaloCalc)

اپلیکیشن اندرویدی کالری‌شمار فارسی: ثبت کالری چهار وعده، کتابخانه غذاهای ایرانی، جستجوی آنلاین Open Food Facts، محاسبه کالری پایه (BMR/TDEE)، برنامه غذایی، ترکر وزن و آب، تقویم جلالی و دو تم روشن/تیره.

این مخزن فقط برای انتشار نسخه‌های رسمی (APK) است؛ سورس‌کد برنامه خصوصی است و در مخزن دیگری نگهداری می‌شود.

## دانلود

- **دانلود مستقیم آخرین نسخه (لینک ثابت و همیشه به‌روز):**
  https://github.com/Shahsavani/calocalc-releases/releases/latest/download/CaloCalc.apk

- **همه نسخه‌ها و تاریخچه تغییرات:**
  https://github.com/Shahsavani/calocalc-releases/releases

## نصب

1. فایل APK را دانلود کنید.
2. در تنظیمات اندروید، اجازه «نصب از منابع ناشناس» را به مرورگر یا فایل‌منیجر خود بدهید.
3. روی فایل دانلودشده بزنید و نصب را تأیید کنید.

## به‌روزرسانی

نسخه‌های جدید به‌محض انتشار، به‌صورت خودکار در بخش Releases همین مخزن قرار می‌گیرند و لینک «دانلود مستقیم» همیشه آخرین نسخه را می‌دهد. همه نسخه‌ها با کلید امضای ثابت ساخته می‌شوند؛ بنابراین نصب نسخه جدید روی نسخه قبلی، بدون حذف برنامه و بدون از دست رفتن داده‌ها انجام می‌شود.

## توضیح فنی

هر نسخه به‌صورت خودکار با GitHub Actions در مخزن خصوصی سورس ساخته، با keystore ثابت CI امضا و در همین مخزن منتشر می‌شود (asset با نام `CaloCalc.apk` همیشه آخرین نسخه release است).
